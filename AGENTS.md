## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## n8n & Şema Tasarım Kuralları
- **n8n Grafikleri ve Şemalarında Koyu Arka Plan Yasağı (Kesin Kural):** n8n iş akışı şemalarında, DAG mimari çizimlerinde, Mermaid ve SVG diyagramlarında **kesinlikle koyu/dark arka plan kullanılamaz**. Arka plan daima saf beyaz (`#FFFFFF`) veya aydınlık/açık-gri (`#F8FAFC`) zemin üzerine yüksek kontrastlı kurumsal renklerle tasarlanır.
